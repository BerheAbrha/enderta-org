# Enderta Organization

The Enderta Organization is a registered 501(c)(3) non-profit in North America dedicated to improving the lives of people in the Enderta region by supporting education and health initiatives.

This repository contains the website content that:

- Highlights the NGO's activities and impact
- Shares news and upcoming events related to the organization
- Describes member participation through monthly membership fees
- Promotes the annual reunion for members
- Accepts one-time donations worldwide via PayPal or Stripe
